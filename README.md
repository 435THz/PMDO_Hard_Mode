# PMDO Hard Mode
By: MistressNebula

This mod adds some settings that aim to make [PMDO](https://github.com/audinowho/PMDODump/releases) harder. Almost none of the mod's effects apply permanent
changes to the Pokémon they modify, save for potentially giving them stronger moves.
Here is a list of all features of the mod. All of these can be toggled at any time in the Settings menu, as long as you are not in a dungeon:

### Settings
 - **Upgrade Movesets** - *Default: On* - All Pokémon spawning in a dungeon will have their moveset swapped out for a randomly generated one. The algorithm that creates these movesets has a bias for stronger moves and for possible synergies between attacks. As the level of the affected pokémon increases, they may also have access to TM, Tutor and Egg moves. Subsequent spawns of the same Pokémon with the same spawn moves will have the same hardmode moveset applied to them.
 - **Moveset Level Bonus** - *Default : Off* - This can be set to any multiple of 5 up to 100. All Pokémon spawning in a dungeon normally only have access to Level Up Moves up to their current level. This setting increases the maximum level they have access to by this number.
 - **Low Level Egg Moves** - *Default: Off* - Activate this setting to give all Pokémon pawning in a dungeon access to one egg move regardless of their level.
 - **Floor Only Movesets** - *Default: Off* - Activate this settings to make the mod reroll movesets at every floor instead of every adventure.
 - **All Moves Enabled** - *Default: On* - All Pokémon will have all their moves enabled even if their spawn data would normally disable some of them. Turning it off will enforce the enabled slot limit on generated movesets, too.
 - **Smarter Enemies** - *Default: Off* - Swap out the AI of newly spawned Pokémon for smarter versions of their intended AI. This mod directly adds many of these upgraded AI plans. *Some of the smartest enemies may even be able to pathfind around traps during aggro*
 - **Stat Increases** - *Default: Off* - Pokémon spawning in a dungeon gain a number of temporary stat increases depending on their level. Higher stats have a higher chance to be boosted. These boosts disappear immediately if the Pokémon is recruited.
 - **Floor Weathers** - *Default: Off* - Whenever you reach a new floor, it may be affected by a map status that depends on the floor's Element. There is also a smaller chance to trigger more peculiar floor effects instead. *Not all elements currently have a weather associated with it. Those that do not will apply a weather that has no gameplay effects*

### Problems
 - When generating a new moveset for higher level Pokémon, the game may freeze for a moment. Hopefully it won't be too big of an issue during gameplay.
